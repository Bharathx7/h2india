# Gate 2: approve Launch 1

Playbook step 9.9 · prepared 13 Nov 2026 · for the H2 India founder.

**Do not sign this yet.** Gate 2 is signed after the Stage 12 checks pass on staging (playbook Section 4). This page says what is ready, what is still open, and what has to happen before you sign.

## What is ready

Stages 1 to 9 are built, each on its own branch (`step/<id>-<name>`), stacked in order and **not merged to `main`**. Launch 1 is the public site, the directory and marketplace (quotes only, prices only on fixed-price product pages), member, supplier and buyer workspaces, RFQs and quotes, and the admin queues. Orders and payments (Batch 6, Stage 10) stay off: the `transactions` flag is off and every order route refuses on the server.

## How it was checked

- `pnpm check` (types, lint, format) and `pnpm test` pass on `step/9.9-flow-a-gate-2`, which holds every earlier step (13 Nov 2026: 182 unit tests passed; database tests skip without `TEST_DATABASE_URL`).
- Integration tests pass against a fresh PostgreSQL with Redis and Mailpit for every step of Stages 7 to 9 (RFQ, messages, buyer, supplier, authz). The file tests need object storage and the virus scanner, so they run in CI.
- Browser tests are written for flows A, C, D, E, G, I and J (`tests/e2e/specs/flow-*.spec.ts` and the step specs) but **have not been run together on staging yet**. That run is the first thing to do before you sign (playbook 9.9 DONE WHEN).

## Before you sign

1. Run all Launch 1 flows together on staging at 1440 and 390 (`E2E_START_SERVER=1 pnpm e2e`, worker and Mailpit running) and attach the report here.
2. Walk flow A yourself as a buyer and as a supplier (search → compare → RFQ wizard → join → moderation → two quotes → comparison → accept-quote screen).
3. Answer or accept the safe default for every item in "Open items that affect Launch 1" below.
4. Stage 12: performance (12.5), accessibility, security review and penetration test (M22), backups and restore, monitoring. Results go in the table at the end.
5. Review and merge the step branches in order (your approval is needed for `main`).
