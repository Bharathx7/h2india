# API routes and server actions

Generated by `pnpm tsx scripts/route-inventory.ts` (playbook step 12.1). Do not edit by hand.

49 route handlers and 236 server actions: 255 call a guard, 30 are public on purpose (allow-list in `apps/web/src/security/route-inventory.ts`).

A guard is a call the scanner recognises in the handler or a helper in the same file. Where the guard only signs the person in (`operatorSession`, `getSession`, `loadActor`), the core function it calls checks the permission and company with `can()` and `scopeFor()`. `route-inventory.test.ts` fails when a new entry has neither a guard nor an allow-list reason.
